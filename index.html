Крокодил:Хаос

Показывай слова без слов. Но не просто так.

Правила
  1. Команды по очереди показывают слова без слов: жесты, мимика, движения. Один показывает, остальные из его команды угадывают.
  2. Перед раундом команда делает ставку: лёгкие слова — 1 очко, средние — 2, безумные — 3. Ставка действует на весь раунд.
  3. К каждому слову выпадает карта условия: показывать нужно именно так.
  4. «Угадали» — очки и следующее слово. «Пропустить» — следующее слово без очков и без штрафа.
  5. Раз за игру каждая команда может подкинуть сопернику «Подлянку»: дополнительное условие на весь его раунд.
  6. Побеждает команда, набравшая больше всех очков.
