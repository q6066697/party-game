# 🐊 Крокодил: Хаос

Весёлая party-игра для компании прямо в браузере. Показывайте слова без слов, но не просто так: каждое слово приходит с безумной **картой условия**, а соперники могут подкинуть вам **«Подлянку»**.

Чистые HTML, CSS и JavaScript: без фреймворков, сборщиков и внешних зависимостей. Работает офлайн.

## Запуск

- **Локально:** откройте `index.html` двойным кликом. Сервер не нужен.
- **Онлайн:** опубликуйте папку на GitHub Pages (инструкция ниже).

Игра адаптирована под телефон, ноутбук и большой экран/ТВ. На ТВ таймер и счёт становятся крупными, их видно с дивана.

## Правила

1. Соберите от 2 до 4 команд, задайте время раунда (30, 60 или 90 секунд) и число раундов на команду.
2. Команды ходят по очереди. В каждом ходе один игрок показывает слова, а его команда угадывает.
3. **«Подлянка»:** перед раундом любая команда-соперник может подкинуть ходящей команде дополнительное условие (например, «с закрытыми глазами»). У каждой команды подлянка одна на всю игру, и на один раунд можно подкинуть только одну.
4. **Ставка:** команда выбирает сложность на весь раунд:
   - 🟢 лёгкое слово: **1 очко**;
   - 🟡 среднее: **2 очка**;
   - 🔴 безумное: **3 очка**.
5. После отсчёта «3-2-1» запускается таймер. Вместе с каждым словом выпадает **карта условия**: «как робот», «в замедленной съёмке», «только звуками»… Показывать нужно именно так.
6. **«Угадали»** даёт очки и следующее слово, **«Пропустить»** даёт следующее слово без очков и без штрафа.
7. Кнопка **«Скрыть»** прячет слово, если на экран могут подсмотреть угадывающие.
8. Когда время выходит, раунд заканчивается, а недопоказанное слово не засчитывается.
9. После всех раундов открывается экран победителя с конфетти и статистикой.

Звук (тиканье в последние секунды, сирена окончания, фанфары) выключается кнопкой 🔊 в правом верхнем углу. Настройки и состояние звука запоминаются в браузере.

## Структура

```
index.html   — разметка всех экранов
style.css    — оформление, анимации, адаптив (телефон / ноутбук / ТВ)
words.js     — база слов, карты условий и карты «Подлянки» (только данные)
game.js      — игровая логика, таймер, звук (Web Audio API), конфетти
README.md    — этот файл
```

## Как добавить слова

Откройте `words.js` и допишите слово в нужную категорию нужной сложности:

```js
easy: {
  'Животные': ['Кошка', 'Собака', /* ... */ 'Ваше слово'],
```

Можно добавить и новую категорию: просто новый ключ с массивом слов. Карты условий (`conditions`) и подлянки (`sabotages`) задаются объектами `{ icon: '🤖', text: 'Как робот' }`.

Слова внутри игры не повторяются, пока колода нужной сложности не закончится. Потом она перемешивается заново.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в его корень все файлы проекта.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через минуту-две игра будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Все пути в проекте относительные, так что дополнительной настройки не требуется.
